## 🚀 Как использовать

### Запуск тестов

```bash
# Все тесты
cd backend/schedule
pytest tests/test_schedule_exporter.py -v

# Конкретный класс
pytest tests/test_schedule_exporter.py::TestFilterByInstructor -v

# С покрытием кода
pytest tests/test_schedule_exporter.py --cov=services.schedule_exporter --cov-report=html
```

### Просмотр логов

```bash
# В консоли при запуске сервера
uvicorn main:app --reload

# В файлах
tail -f backend/schedule/logs/schedule_*.log
```

### Примеры вызовов API с логированием

```bash
# XLSX с фильтром по преподавателю
curl "http://localhost:8000/api/schedule/export/xlsx?instructor=Иванов&separate_courses=true"

# PDF с поиском по названию
curl "http://localhost:8000/api/schedule/export/pdf?title_search=математика"

# Комбинированная фильтрация
curl "http://localhost:8000/api/schedule/export/xlsx?instructor=Петров&auditorium_ids=1&auditorium_ids=2"
```
