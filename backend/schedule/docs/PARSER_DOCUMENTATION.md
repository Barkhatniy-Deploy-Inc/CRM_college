# Переделанный парсер расписания

## Обзор

Новый парсер обрабатывает Excel файлы расписания согласно реальной структуре документов СурГУ.

## Структура файлов расписания

### Формат Excel файла:
- **Строки 1-5**: Заголовок документа с утверждениями и информацией о периоде
- **Строка 6**: Шапка таблицы с названиями колонок
  - Колонка 0: Пусто (N/A)
  - Колонка 1: "Дата"
  - Колонка 2: "Занятие"
  - Колонка 3: "Время"
  - Колонки 4+: Чередующиеся пары (Группа, Аудитория)
- **Строки 7+**: Данные по дням и занятиям

### Структура листов:
- Каждый файл содержит несколько листов (по одному на курс)
- Примеры: "01.09 - 1 курс", "01.09 - 2 курс", и т.д.
- Служебный лист "ЗВОНКИ" пропускается при парсинге

## Возвращаемые данные

Каждое занятие представлено словарём с полями:

```python
{
    'group_name': str,           # Название группы (например, "ПД-25/9-П")
    'date': str,                 # Дата в формате "ДД.MM.ГГГГ"
    'day_of_week': int,          # День недели (1=пн, 2=вт, ..., 7=вс)
    'time_slot': str,            # Время в формате "ЧЧ:ММ-ЧЧ:ММ" (например, "09:40-10:40")
    'pair_number': int | None,   # Номер пары (1-8) или None
    'subject': str,              # Название предмета
    'teacher': str | None,       # ФИО преподавателя (формат "Фамилия И.О.") или None
    'auditorium': str | None,    # Номер аудитории или None
    'sheet_name': str            # Название листа источника (например, "01.09 - 1 курс")
}
```

## Использование

### Основное использование:

```python
from core.parser import parse_excel_schedule

# Парсить файл расписания
entries = parse_excel_schedule('path/to/schedule.xlsx')

# entries - это список словарей с полной информацией о занятиях
for entry in entries:
    print(f"{entry['group_name']} - {entry['subject']} в {entry['time_slot']}")
```

### Фильтрация данных:

```python
# Все занятия группы ПД-25/9-П
group_lessons = [e for e in entries if e['group_name'] == 'ПД-25/9-П']

# Занятия в определённую дату
date_lessons = [e for e in entries if e['date'] == '01.09.2025']

# Занятия конкретного преподавателя
teacher_lessons = [e for e in entries if e['teacher'] and 'Туманова' in e['teacher']]

# Занятия в конкретной аудитории
room_lessons = [e for e in entries if e['auditorium'] == '244']
```

## Особенности реализации

### Автоматическое извлечение информации:
1. **День недели и дата**: Извлекаются из первой ячейки каждого дня
   - Формат: "ПОНЕДЕЛЬНИК ... 01.09.2025"
   
2. **Предмет и преподаватель**: Парсятся из одной ячейки с использованием регулярных выражений
   - Формат: "Предмет                          Фамилия И.О."
   - Разделитель: ФИО определяется по паттерну "Фамилия И.О."

3. **Время занятия**: Извлекается прямо из Excel в формате "ЧЧ:ММ-ЧЧ:ММ"

4. **Номер пары**: Определяется из колонки "Занятие" (1-8)

### Логирование:
- INFO уровень: Информация о обработке листов и общее количество спарсенных занятий
- DEBUG уровень: Детали при возникновении проблем с извлечением дат или заголовков
- ERROR уровень: Критические ошибки при открытии файла или обработке листа

```bash
python test_parser_new.py
```

Результат включает:
- Количество спарсенных занятий
- Таблицу первых 30 занятий
- Статистику по группам
- Пример полного объекта занятия

## Интеграция с API

Парсер используется в `api/schedule_api.py` в функции `upload_schedule()`:

```python
from core.parser import parse_excel_schedule

entries = parse_excel_schedule(temp_path)
# Теперь entries содержит полную информацию о расписании
```
