### 1. 📧 Email верификация и восстановление пароля

**Приоритет:** 🔥 Высокий

**Что добавить:**
- Подтверждение email при регистрации
- Восстановление пароля через email
- Сброс пароля по токену

**Эндпоинты:**
```
POST /api/auth/verify-email          - Подтверждение email
POST /api/auth/resend-verification  - Повторная отправка кода
POST /api/auth/forgot-password      - Запрос на восстановление
POST /api/auth/reset-password       - Сброс пароля по токену
```

**Технологии:**
- SMTP сервер (Gmail, SendGrid, Mailgun)
- Токены верификации (JWT с коротким сроком жизни)
- Шаблоны писем (Jinja2)

**Модели:**
```python
class EmailVerification(Base):
    user_id: int
    token: str
    expires_at: datetime
    verified: bool
```

### 3. 🔍 Поиск и фильтрация пользователей

**Приоритет:** 🟡 Средний

**Что добавить:**
- Поиск пользователей по email, имени
- Фильтрация по ролям, статусу
- Пагинация
- Сортировка

**Эндпоинты:**
```
GET /api/users?search=email&role=student&is_active=true&page=1&limit=20
```

**Параметры:**
- `search` - поиск по email/имени
- `role` - фильтр по роли
- `is_active` - фильтр по активности
- `is_verified` - фильтр по верификации
- `page`, `limit` - пагинация
- `sort` - сортировка (created_at, email, etc.)

### 4. 🛡️ Управление разрешениями через API

**Приоритет:** 🟡 Средний

- CRUD операции для разрешений
- Выдача/отзыв разрешений пользователям

**Эндпоинты:**
```
# Разрешения

DELETE /api/permissions/{id}         - Удаление разрешения

# Разрешения пользователей
GET    /api/users/{user_id}/permissions - Разрешения пользователя
POST   /api/users/{user_id}/permissions - Выдача разрешения
DELETE /api/users/{user_id}/permissions/{perm_id} - Отзыв разрешения
```
