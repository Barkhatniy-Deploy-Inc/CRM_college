# Технологический стек: CRM College

## Бэкенд (Python)
- **Язык:** Python 3.11+
- **Фреймворк:** FastAPI (высокопроизводительный API)
- **ORM:** SQLAlchemy (работа с базой данных)
- **Валидация данных:** Pydantic v2
- **Драйвер БД:** Psycopg 3
- **Тестирование:** Pytest, Pytest-asyncio
- **Кэширование:** Redis

## Фронтенд (Vue.js)
- **Инструмент сборки:** Vite.js (быстрая разработка и сборка)
- **Фреймворк:** Vue.js 3 (Composition API)
- **Управление состоянием:** Pinia
- **Навигация:** Vue Router
- **Язык:** JavaScript
- **Архитектура:** Структурирование компонентов по фичам (Feature-based structure)
- **Тестирование:** Vitest (конфигурация и юнит-тесты)

## База данных
- **Основная БД:** PostgreSQL (реляционная база данных)

## Инфраструктура и DevOps
- **Контейнеризация:** Docker, Docker Compose
- **Прокси-сервер:** Nginx (Gateway)
- **CI/CD:** GitHub Actions (автоматизация тестирования и деплоя)

## Стандарты качества
- **Покрытие тестами:** >80% (для всех слоев приложения)
- **Стиль кода:** PEP 8 (для Python), ESLint/Prettier (для JS/Vue)
