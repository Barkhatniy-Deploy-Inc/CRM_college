# Specification: Продвинутый конструктор расписания и Редактор связей

## 1. Обзор
Внедрение профессионального конструктора расписания с поддержкой Drag & Drop, интеллектуальных подсказок и системы управления связями "Преподаватель - Урок - Кабинет".

## 2. Функциональные требования

### 2.1 Редактор связей (Новый модуль)
- Интерфейс для настройки привязок:
    - **Преподаватель ↔ Предмет**: Кто ведет данную дисциплину.
    - **Предмет ↔ Кабинеты**: Список рекомендуемых кабинетов для конкретного урока.
- Данные используются для автозаполнения в конструкторе.

### 2.2 Интеллектуальный Конструктор
- **Drag & Drop**: Перенос предметов из бокового меню в сетку.
- **Автозаполнение**: Автоматическая подстановка кабинета при постановке урока.
- **Гибкость**: Автоподстановка не блокирует ручное изменение.
- **Выпадающий список**: Клик по ячейке открывает меню с предметами группы.
- **Функционал замен**: Возможность локально изменить преподавателя для конкретного урока.

### 2.3 Интерфейс выбора кабинета
- Выпадающий список с рекомендованными кабинетами.
- Поле для ручного ввода номера кабинета.

### 2.4 Контроль конфликтов и Сохранение
- Визуальная подсветка занятых преподавателей/кабинетов (красным).
- Autosave в БД + кнопка "Опубликовать".
- Экспорт в XLSX/PDF.

## 3. Критерии приемки
1. Наличие раздела "Редактор связей".
2. Автоматическая подстановка кабинета при Drag&Drop на основе настроенных связей.
3. Возможность вручную изменить кабинет или преподавателя в ячейке.
4. Файлы XLSX и PDF генерируются и скачиваются корректно.
