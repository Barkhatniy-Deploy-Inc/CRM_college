## 🚀 Инструкции по развертыванию

### Для разработки:

1. **Скопируйте файл с переменными окружения:**
   ```bash
   cp backend/schedule/.env.example backend/schedule/.env
   ```

2. **Заполните обязательные переменные в .env:**
   ```bash
   # Обязательные переменные
   SECRET_KEY=your_super_secret_key_minimum_32_characters
   DB_PASSWORD=your_secure_database_password
   
   # Опциональные (имеют значения по умолчанию)
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=schedule_db
   DB_USER=postgres
   ALLOWED_ORIGINS=http://localhost:3000
   ```

3. **Запустите базу данных для разработки:**
   ```bash
   docker-compose -f docker-compose.dev.yml up -d
   ```

4. **Запустите backend сервисы:**
   ```bash
   cd backend/schedule
   pip install -r requirements.txt
   uvicorn main:app --reload
   ```

### Для production:

1. **Создайте .env файл с production настройками:**
   ```bash
   # КРИТИЧЕСКИ ВАЖНО: Используйте сильные пароли!
   SECRET_KEY=your_production_secret_key_64_characters_minimum
   DB_PASSWORD=your_production_database_password
   DB_HOST=your_production_db_host
   ALLOWED_ORIGINS=https://yourdomain.com,https://www.yourdomain.com
   ENVIRONMENT=production
   ```

2. **Запустите с Docker Compose:**
   ```bash
   docker-compose up -d
   ```
